Sözleşme eki: ilk akışın örnekli paketi

Bu ek, geliştirmeden önce yazılması kararlaştırılan örnekli sözleşme paketidir (karar kitabı V08). Ne işe yarar: frontend, Frappe custom app ve model tarafı aynı örneği okuyarak başlar; hiçbiri kendi şemasını uydurmaz. Ne yapar: ilk dilimin tek akışını ("seçili ürünlerin eksik özniteliklerini tamamla") altı yapıda örnekler: capability manifesti → Run başlatma isteği → öneri (ChangeSet) → onay → sonuç → görünüm (UI Spec). Ne yapmaz: bütün capability'leri tanımlamaz; her yeni akış bu kalıpla kendi ekini yazar. Asıl kaynak zod şemalarıdır; buradaki JSON örnekleri o şemalardan geçen geçerli örneklerdir ve aynı örnekler CI'da hem TypeScript hem Python tarafında sınanır (B2, TP-01). Parmak izleri F9'daki kuralla hesaplanır. Alanların kimden geldiği her örneğin altında yazılıdır: Z zorunlu, İ istemci gönderir, S sunucu türetir (istemci gönderse bile sunucu yok sayar ve kendisi yazar).

1 · Capability manifesti girdisi

{
  "capability": "pim.fill_missing_attributes",
  "version": "1.0.0",
  "doctype": "Item",
  "modes": ["assisted", "delegated"],
  "risk": { "base": "reversible", "escalate_when": { "records_over": 50, "sensitive_fields": true, "submit_or_delete": true } },
  "reversibility": { "kind": "previous_value", "undo_window_s": 30 },
  "grant_eligible": true,
  "step_up": null,
  "offline_allowed": false,
  "retry": "retryable",
  "params_schema": "genui.contracts/pim.fill_missing_attributes.params@1",
  "limits": { "max_records": 200, "max_steps": 20, "timeout_s": 600 }
}

Manifest tamamen sunucu verisidir (S); metadata'dan üretilir ve açık allowlist ile daraltılır. risk.escalate_when, C01 kararının makine okunur hâlidir: 50'yi aşan küme ve hassas alan içeren küme sınıf yükseltir.

2 · Run başlatma isteği

POST /api/v2/method/genui.api.v1.runs.start
{
  "capability": "pim.fill_missing_attributes",
  "capability_version": "1.0.0",
  "mode": "assisted",
  "selection": {
    "doctype": "Item",
    "filter": { "op": "and", "args": [
      { "field": "item_group", "op": "=", "value": "Küçük Ev Aletleri" },
      { "field": "description", "op": "is_empty" }
    ] },
    "exclude": ["ITEM-00017"]
  },
  "context_manifest_fingerprint": "5d1c…e07a",
  "idempotency_key": "01J9ZK3T6Q8M4R2W7Y5N0B1C3D"
}

Z ve İ: capability, capability_version, mode, selection, context_manifest_fingerprint, idempotency_key. İ: exclude. Yanıtta S: run_id, tenant ve kullanıcı, risk_class (sunucu hesaplar), estimate (kayıt sayısı, süre, maliyet), created_at. Geçersiz örnek: isteğe "sql" veya "url" alanı eklemek; şema z.strictObject olduğu için istek reddedilir ve güvenlik olayı yazılır (G1, G5).

Tamamı S. confidence kalibrasyon bitene kadar null'dır (I4, Y05). ambiguous kayıt değişiklik taşımaz ve uygulanmaz (Y06). Geçersiz örnek: izin projeksiyonunda olmayan bir alanı değiştiren öğe; sunucu ChangeSet'i üretmeden reddeder.

4 · Onay

POST /api/v2/method/genui.api.v1.changesets.approve
{
  "changeset_id": "CS-2026-00418",
  "changeset_fingerprint": "c41a…77d2",
  "approved_items": ["ITEM-00012"],
  "excluded_items": ["ITEM-00020"],
  "idempotency_key": "01J9ZK4B2C…"
}

Z ve İ: changeset_id, changeset_fingerprint, approved_items, idempotency_key. İ: excluded_items. Yanıtta S: approval_id, decision (approved veya partially_approved), onaylayan, via (user veya grant ve grant_id), approved_at, expires_at (öneride 10 dakika). Geçersiz örnek: parmak izi sunucudakiyle eşleşmiyorsa onay reddedilir ve hata kodu approval_stale döner (B11); ChangeSet yeniden incelenir.

  ],
  "undo_until": "2026-09-29 10:22:10.552",

Tamamı S ve izinli REST ile okunur; Socket.IO yalnızca "Run değişti" sinyali taşır (B6, C03). Kayıt başına sonuç F6'ya uyar; seçmeli yeniden deneme yalnızca conflict ve failed kayıtları hedefler.

6 · Görünüm (UI Spec)

{
  "specVersion": "1",
  "catalogId": "genui.core",
  "catalogVersion": "3.2.0",
  "schemaFingerprint": "9f3c…a41b",
  "surfaceId": "run-result-RUN-2026-00418",
  "elements": {
    "root": { "type": "Stack", "children": ["summary", "remaining"] },
    "summary": { "type": "BatchResult", "props": { "run": "RUN-2026-00418" } },
    "remaining": { "type": "EntityTable", "props": { "doctype": "Item", "columns": ["item_name", "description"] } }
  },
  "dataBindings": { "remaining": { "capability": "pim.list", "filter": { "op": "in", "field": "name", "valueRef": "run:RUN-2026-00418:unresolved" } } },
  "actions": [{ "id": "retry", "capability": "runs.retry_failed", "risk": "reversible" }]
}

Spec veri taşımaz, yalnızca veri bağlama referansı taşır (D7); renderer kataloğu dışında tip veya prop reddedilir (D1). Model bu spec'i önerir; sunucu doğrular, istemci çizmeden önce yeniden doğrular.
